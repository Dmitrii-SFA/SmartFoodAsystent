# Квадратная кнопка «Добавить на главный экран» в шапке Настроек

Добавление компактной квадратной кнопки установки приложения на главный экран смартфона в самом верху вкладки «Настройки» — справа от заголовка «Разделы настроек».

## Подтверждённые решения пользователя

> [!IMPORTANT]
> Следующие параметры согласованы и положены в основу реализации:
> - **Логика работы на смартфонах**: При наличии системного диалога установки (`beforeinstallprompt` на Android / Chrome) сразу вызывается системное окно добавления иконки на главный экран; для iPhone (Safari) и других браузеров открывается наглядное всплывающее окно с иконкой приложения и пошаговой инструкцией.
> - **Условие отображения**: Квадратная кнопка отображается в верхней строке настроек справа от заголовка разделов и автоматически скрывается, когда приложение уже установлено и запущено с главного экрана (`standalone`-режим).

---

## 1. Обзор и основная концепция

- **Что делает функция**: Позволяет одним нажатием на аккуратную квадратную кнопку в правом верхнем углу вкладки «Настройки» вывести приложение на главный экран смартфона с фирменной иконкой.
- **Целевая аудитория и сценарий**: Пользователи мобильных устройств (Android и iOS), желающие запускать дневник питания как полноценное приложение с рабочего стола телефона без адресной строки браузера.
- **Ключевая ценность**: Быстрый доступ к установке в предсказуемом месте настроек без перегруженности шапки лишним текстом, а также автоматическое исчезновение кнопки после установки.

---

## 2. Пользовательский опыт и визуальный дизайн

- **Расположение и внешний вид кнопки**:
  - В самой верхней строке вкладки «Настройки» (`Разделы настроек · X из 10`) справа размещается небольшая квадратная кнопка (`aspect-square`, размер $38 \times 38\text{ px}$ с удобной областью касания), оформленная в цветах активной темы и акцентного цвета приложения.
  - Внутри кнопки отображается иконка смартфона со значком добавления на экран и всплывающая подсказка «Добавить на главный экран» (локализованная на русский, английский и польский языки).
- **Пошаговый сценарий при нажатии**:
  1. **Прямая установка (Android / Chromium)**: Если браузер подготовил системное событие установки, нажатие мгновенно открывает системное окно смартфона «Добавить приложение на главный экран». После подтверждения приложение создаёт ярлык на рабочем столе, а кнопка автоматически скрывается.
  2. **Инструкция с иконкой (iPhone / iPad и браузеры без прямого вызова)**: Открывается аккуратное модальное окно с предпросмотром иконки приложения и понятными шагами для iOS Safari («Поделиться» → «На экран "Домой"») и Android-браузеров («Меню браузера ⋮» → «Добавить на главный экран» / «Установить приложение»).

---

## 3. Ключевые продуктовые решения и компромиссы

- **Решение 1: Глобальный перехват события установки с момента старта приложения**
  - *Выбранный подход*: Событие браузера `beforeinstallprompt` перехватывается и сохраняется сразу при загрузке приложения (ещё до перехода пользователя во вкладку «Настройки»), чтобы к моменту открытия настроек кнопка могла мгновенно вызвать системный диалог установки.
  - *Почему*: Браузеры генерируют `beforeinstallprompt` только один раз при старте страницы; если слушать его только внутри вкладки настроек, событие может быть пропущено.
- **Решение 2: Определение режима запуска с главного экрана (`standalone`)**
  - *Выбранный подход*: Проверка медиа-выражения `(display-mode: standalone)`, свойства `navigator.standalone` (для iOS) и события `appinstalled`.
  - *Почему*: Гарантирует, что когда пользователь открывает приложение уже с иконки на смартфоне, кнопка «Добавить на главный экран» не занимает место в шапке настроек.

## 4. Техническая архитектура и поток данных

```
┌──────────────────────────────────────────────────────────────────────┐
│                  Шапка вкладки «Настройки» (Верхняя строка)          │
│  ┌────────────────────────────────────┐        ┌──────────────────┐  │
│  │ ⚙ Разделы настроек   [ X из 10 ]   │        │ [ 📱+ ] Квадрат  │  │
│  └────────────────────────────────────┘        └────────┬─────────┘  │
└─────────────────────────────────────────────────────────┼────────────┘
                                                          │
                         Нажатие на кнопку                ▼
               ┌────────────────────────────────────────────────────┐
               │ Проверка состояния установки (PWA Install Manager) │
               └───────────────────┬──────────────────────┬─────────┘
                                   │                      │
         Доступен системный вызов  │                      │ iOS / встроенный браузер
                                   ▼                      ▼
               ┌──────────────────────────────┐  ┌─────────────────────────────┐
               │ Вызов системного окна        │  │ Модальное окно с иконкой    │
               │ установки смартфона          │  │ приложения и пошаговой      │
               │ (создание иконки на экране)  │  │ инструкцией для iOS/Android │
               └──────────────────────────────┘  └─────────────────────────────┘
```

- **Состояние и синхронизация**:
  - Хранение отложенного события установки на глобальном уровне окна, чтобы оно было доступно при любом переключении вкладок.
  - Автоматическая реакция на событие успешной установки (`appinstalled`) с мгновенным скрытием квадратной кнопки.
