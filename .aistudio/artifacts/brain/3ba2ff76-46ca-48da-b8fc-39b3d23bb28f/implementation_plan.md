# Развёртывание на Cloudflare с секретным ключом и цепочкой моделей Gemini 3.5 Flash-Lite

Подготовка приложения к открытию и работе непосредственно на платформе Cloudflare (Cloudflare Workers / Cloudflare Pages) с использованием засекреченной переменной окружения `GEMINI_API_KEY` на стороне Cloudflare, полным устранением ошибки `405 Method Not Allowed` при `POST`-запросах и настройкой модели **Gemini 3.5 Flash-Lite** с каскадным фоллбэком до **Gemini 2.5 Flash-Lite** и далее.

## User Review & Critical Decisions

> [!IMPORTANT]
> Нажмите кнопку **Proceed** («Продолжить») внизу карточки плана, чтобы применить эти изменения в коде проекта.

- **Работа приложения напрямую на домене Cloudflare**: Приложение сможет открываться прямо по ссылке вашего проекта в Cloudflare. Серверный обработчик (`worker.js` + `wrangler.toml`, а также `functions/api/ai.js` для Cloudflare Pages) будет раздавать статику интерфейса на `GET`-запросы и перехватывать все `POST`-запросы к ИИ, используя засекреченный ключ `env.GEMINI_API_KEY` из настроек Cloudflare.
- **Каскадная цепочка моделей (Fallback Chain)**:
  1. `gemini-3.5-flash-lite` (основная модель)
  2. `gemini-3.1-flash-lite` (первый фоллбэк)
  3. `gemini-2.5-flash-lite` (второй фоллбэк)
  4. `gemini-2.5-flash` (третий фоллбэк)
  5. `gemini-flash-latest` (завершающий резервный алиас)

## 1. Overview & Core Concept

- **Что делает изменение**: Обеспечивает работу как клиентской части (React PWA), так и серверного ИИ-прокси внутри единого проекта Cloudflare без раскрытия API-ключа в браузере и без ошибки `405 Method Not Allowed`.
- **Ключевая ценность**:
  - Секретный ключ `GEMINI_API_KEY` хранится только в защищённом хранилище Cloudflare (`Settings -> Variables and Secrets`) и никогда не попадает в клиентский бандл.
  - Любой `POST`-запрос (сканирование этикетки, фото тарелки, генерация рецепта, кулинарная физика, чат) обрабатывается серверной функцией Cloudflare, а при недоступности конкретной версии модели автоматически переключается по цепочке фоллбэков.

---

## 2. User Experience & Visual Design

- **Бесшовная отправка фото и запросов**: Когда пользователь открывает приложение на Cloudflare и делает снимок этикетки или блюда, запрос отправляется на серверный обработчик Cloudflare (с автоматическим резервированием между локальным маршрутом `/api/ai` на том же домене Cloudflare и внешним воркером `https://api.smartfoodasystent.workers.dev`).
- **Индикация модели**: В интерфейсе чата и конфигурации отображается **Gemini 3.5 Flash-Lite** (`gemini-3.5-flash-lite`).
- **Сохранение системы доступа и лимитов**: Полностью сохраняются суточные квоты (20 запросов в сутки в пробном режиме, 100 запросов в сутки по годовому ключу `app_access_key`), анти-спам (10 секунд между запросами, максимум 3 в минуту) и окно «Полный доступ на 1 год».

## 3. Key Product Decisions & Trade-Offs

- **Решение 1: Поддержка обоих режимов деплоя Cloudflare (Workers Static Assets и Cloudflare Pages)**
  - *Выбранный подход*:
    1. В корень проекта добавляются `worker.js` и `wrangler.toml` с `run_worker_first = true` в секции `[assets]`, чтобы Cloudflare Workers не блокировал `POST`-запросы статическим сервером (`405 Method Not Allowed`).
    2. Дополнительно создаётся обработчик `functions/api/ai.js`, чтобы даже при деплое через **Cloudflare Pages** маршрут `/api/ai` автоматически становился серверной функцией с доступом к `env.GEMINI_API_KEY`.
    3. На клиенте запросы отправляются сначала на серверный эндпоинт воркера (и при необходимости дублируются на `/api/ai` текущего домена Cloudflare, если внешний URL вернул `405` или сетевую ошибку).
  - *Почему*: Это на 100% исключает ошибку `405 Method Not Allowed` независимо от того, как именно проект подключён в панели Cloudflare (как Worker или как Pages).

- **Решение 2: Автоматический каскадный фоллбэк моделей на сервере**
  - *Выбранный подход*: При получении запроса серверный обработчик пробует модели по очереди:
    `['gemini-3.5-flash-lite', 'gemini-3.1-flash-lite', 'gemini-2.5-flash-lite', 'gemini-2.5-flash', 'gemini-flash-latest']`.
    Если Google API возвращает `404` или ошибку неподдерживаемой модели для `gemini-3.5-flash-lite`, воркер мгновенно выполняет запрос к следующей модели в списке и возвращает результат клиенту.
  - *Почему*: Пользователь не видит ошибок при смене версий или региональных ограничениях моделей в Google AI Studio.

## 4. Technical Architecture & Data Strategy

```
┌──────────────────────────────────────────────────────────────────────────┐
│           Клиентское приложение (открыто на домене Cloudflare)           │
│  Камера (этикетка / блюдо) • Генератор рецептов • Чат-ассистент          │
│  Запрос: POST (JSON: model="gemini-3.5-flash-lite", contents=[...])      │
└────────────────────────────────────┬─────────────────────────────────────┘
                                     │
                                     ▼
┌──────────────────────────────────────────────────────────────────────────┐
│     Серверный слой Cloudflare (worker.js + wrangler.toml / functions)    │
│  • Перехватывает OPTIONS (204 + CORS) и POST до обращения к статике      │
│  • Берёт засекреченный ключ из env.GEMINI_API_KEY                        │
│  • GET-запросы передаёт в env.ASSETS (открывает интерфейс приложения)    │
└────────────────────────────────────┬─────────────────────────────────────┘
                                     │
                                     ▼
┌──────────────────────────────────────────────────────────────────────────┐
│                  Каскадный вызов Google Gemini REST API                  │
│  1. gemini-3.5-flash-lite                                                │
│  2. └─(при 404/400 model error)─► gemini-3.1-flash-lite                  │
│  3.                                └─► gemini-2.5-flash-lite             │
│  4.                                     └─► gemini-2.5-flash             │
│  5.                                          └─► gemini-flash-latest     │
└──────────────────────────────────────────────────────────────────────────┘
```

- **Локальная среда разработки (`server.ts` / `aiService.js`)**:
  - Локальный сервер разработки также обновляется на поддержку маршрута `/api/ai` и цепочки фоллбэков `gemini-3.5-flash-lite` → `gemini-3.1-flash-lite` → `gemini-2.5-flash-lite` → `gemini-2.5-flash` → `gemini-flash-latest`, чтобы поведение в превью и в продакшене на Cloudflare было идентичным.
