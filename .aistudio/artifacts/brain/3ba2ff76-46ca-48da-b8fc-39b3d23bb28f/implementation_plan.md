# Переход на модель Gemini 3.5 Flash-Lite в серверном прокси

План описывает точечную замену идентификатора модели по умолчанию с `gemini-2.5-flash-lite` на `gemini-3.5-flash-lite` во всех серверных обработчиках запросов к ИИ.

## Согласованные решения

> [!IMPORTANT]
> По результатам уточнения замена выполняется строго по заданному идентификатору и только в тех местах, где ранее была прописана модель `gemini-2.5-flash-lite`.

- **Идентификатор модели**: везде, где задавалась модель по умолчанию `gemini-2.5-flash-lite`, устанавливается строго `gemini-3.5-flash-lite`.
- **Область изменений**: обновляются только серверные обработчики прокси-запросов (Cloudflare Worker, Pages Worker, Pages Function и локальный прокси-маршрут), без изменения остальных частей интерфейса и конфигурации.

---

## 1. Обзор и суть решения

- **Что делает изменение**: при отправке любого POST-запроса к ИИ (оценка продукта по названию, распознавание фото этикетки или блюда, генерация рецепта, чат), если клиент явно не переопределил поле `model`, серверный прокси обращается к эндпоинту Google Gemini API с моделью `gemini-3.5-flash-lite`.
- **Ключевая ценность**: единая версия модели `gemini-3.5-flash-lite` во всех вариантах деплоя (Cloudflare Workers, Cloudflare Pages и локальная среда).

---

## 2. Пользовательский опыт

- Поведение интерфейса остаётся прежним: все кнопки ИИ-анализа, сканирования и генерации рецептов продолжают работать прозрачно для пользователя, отправляя запросы через обновлённый серверный обработчик.

---

## 3. Ключевые технические решения

1. **Строгое соответствие идентификатора модели**:
   - *Выбранный подход*: установка значения по умолчанию `const targetModel = requestData.model || "gemini-3.5-flash-lite";`.
   - *Почему*: полностью соответствует вашему требованию использовать `gemini-3.5-flash-lite` во всех точках, где ранее стояла `gemini-2.5-flash-lite`.

---

## 4. Техническая архитектура

```
│                   Клиентское приложение (React PWA)                  │

                                   │
                                   ▼
┌──────────────────────────────────────────────────────────────────────┐
│               Серверный прокси-слой (Cloudflare / Local)             │

└──────────────────────────────────┬───────────────────────────────────┘
                                   │
                                   ▼
┌──────────────────────────────────────────────────────────────────────┐

└──────────────────────────────────────────────────────────────────────┘
```
