# План реализации: выбор нутриентов, синхронизация цветов и расчёт суточной нормы для всех отслеживаемых показателей

## 1. Обзор и подтверждённые решения

Цель обновления — выстроить последовательную логику настройки трекера питания: сначала пользователь выбирает отслеживаемые нутриенты, затем настраивает или рассчитывает с помощью ИИ суточную норму для всех выбранных показателей, при полном визуальном соответствии цветов нутриентов во всех вкладках приложения.

### Подтверждённые параметры:
1. **Порядок разделов в Настройках**: раздел выбора и настройки всех нутриентов размещается сразу после выбора языка интерфейса и перед разделом «Суточная норма».
2. **Группировка в разделе выбора нутриентов**: основные нутриенты (Калории, Белки, Жиры, Углеводы, Вода и любые закреплённые пользователем как основные) отображаются сразу и выбраны по умолчанию, а все остальные второстепенные нутриенты (клетчатка, сахар, витамины, минералы и др.) свёрнуты под кнопкой разворачивания.
3. **Отображение нутриентов в разделе «Суточная норма»**: основные нутриенты показываются сразу в верхнем блоке, а выбранные пользователем второстепенные отслеживаемые нутриенты размещаются под кнопкой разворачивания внутри «Суточной нормы».
4. **Редактирование норм в обоих разделах**: поля ввода целевых цифр нормы сохраняются как в разделе выбора всех нутриентов, так и в разделе «Суточная норма» (изменения синхронизированы).
5. **Единая цветовая кодировка**: цвета основных и дополнительных нутриентов в «Суточной норме» приводятся в точное соответствие с цветами в «Дневном меню» и «Продуктах» (Калории — оранжевый `#f97316`, Белки — синий `#3b82f6`, Жиры — жёлтый `#eab308`, Углеводы — красный `#ef4444`, Клетчатка — зелёный `#22c55e`, Вода — голубой `#06b6d4`, а также индивидуальные цвета остальных показателей).
6. **Расчёт ИИ для всех выбранных нутриентов**: при нажатии «Посчитать с помощью ИИ» запрос передаёт список всех отслеживаемых пользователем нутриентов (включая выбранные второстепенные, такие как сахар, клетчатка, холестерин, витамины и минералы) и автоматически заполняет их суточные нормы.

## 2. Архитектура и поток данных

```
+-----------------------------------------------------------------------+
|                           Раздел «Настройки»                          |
+-----------------------------------------------------------------------+
                                   |
                                   v
+-----------------------------------------------------------------------+
| 1. Язык интерфейса                                                    |
+-----------------------------------------------------------------------+
                                   |
                                   v
+-----------------------------------------------------------------------+
| 2. Настройка всех нутриентов и норм                                   |
|    - Основные нутриенты (КБЖУ, Вода) — видны сразу и активны          |
|    - [Кнопка: Развернуть второстепенные нутриенты (N)]                |
|      └─ Сахар, Клетчатка, Витамины, Минералы (вкл/выкл + ввод нормы)  |
+-----------------------------------------------------------------------+
                                   |
            Передача списка выбранных нутриентов и их цветов
                                   |
                                   v
+-----------------------------------------------------------------------+
| 3. Суточная норма                                                     |
|    - Основные нутриенты (единые цвета с Дневным меню и Продуктами)    |
|    - [Кнопка: Выбранные дополнительные нутриенты (N)]                 |
|      └─ Поля ручного ввода норм для выбранных второстепенных          |
|    - [Кнопка: Посчитать с помощью ИИ]                                 |
|      └─ Пол, возраст, вес, рост, цель, 5 уровней + своя активность    |
|      └─ ИИ рассчитывает нормы для ВСЕХ выбранных нутриентов           |
+-----------------------------------------------------------------------+
```

## 3. Детальный план изменений

### Шаг 1. Перестановка разделов в Настройках
- Переместить карточку настройки всех нутриентов и норм на позицию между карточкой «Язык интерфейса» и карточкой «Суточная норма».

### Шаг 2. Сворачивание второстепенных нутриентов в разделе настройки нутриентов
- Разделить список нутриентов на две группы:
  - **Основные нутриенты** (`calories`, `proteins`, `fats`, `carbs`, `water` и пользовательские с флагом основного блока) — отображаются сразу и включены для отслеживания.
  - **Второстепенные нутриенты** — скрыты по умолчанию под интерактивной кнопкой-переключателем (например, «Показать остальные нутриенты» / «Скрыть второстепенные нутриенты» с индикатором количества выбранных и общего числа).
- Сохранить возможность прямого ввода нормы, переключения видимости и выбора цвета для каждого нутриента.

### Шаг 3. Синхронизация цветов и поддержка выбранных второстепенных нутриентов в «Суточной норме»
- Использовать единый источник цвета каждого нутриента (как в «Дневном меню» и «Продуктах») для рамок, акцентов и текста полей ввода в «Суточной норме».
- Отображать основные отслеживаемые нутриенты сразу в первой сетке ручного ввода.
- Добавить под основными нутриентами кнопку разворачивания выбранных второстепенных нутриентов (если пользователь включил хотя бы один второстепенный показатель, например сахар, клетчатку, натрий или витамины), внутри которой находятся поля ручного ввода суточной нормы для каждого выбранного показателя с его единицей измерения и цветом.

### Шаг 4. Расчёт суточной нормы через ИИ для всех выбранных нутриентов
- Обновить функцию обращения к ИИ через воркер так, чтобы в запрос передавался перечень всех выбранных пользователем нутриентов (их идентификаторы, названия и единицы измерения).
- При получении ответа от ИИ обновлять значения как основных (КБЖУ и вода), так и всех выбранных второстепенных нутриентов в полях ввода и сохранять их в общую конфигурацию приложения.
