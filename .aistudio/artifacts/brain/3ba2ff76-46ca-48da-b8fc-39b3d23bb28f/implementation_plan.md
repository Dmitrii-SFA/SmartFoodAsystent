# План реализации: Кнопка «Изменить» в Дневном меню и в Списке продуктов

## 1. Кнопка «Изменить» для продукта в Дневном меню
- **Расположение**: В строке каждого продукта внутри приёма пищи (`ReorderableMealTimeline.tsx`) добавить кнопку **«Изменить»** (иконка карандаша `Edit3`) слева от кнопок «Добавить в список покупок» и «Удалить». Итоговый порядок кнопок в карточке продукта:
  1. **Изменить** (слева)
  2. **Добавить в список покупок**
  3. **Удалить**
- **Функционал**:
  - При нажатии на кнопку «Изменить» открывается компактное модальное окно редактирования веса продукта в граммах (с быстрыми кнопками `50г`, `100г`, `150г`, `200г`, `250г`, `300г` и полем ручного ввода граммов).
  - При сохранении нового веса все нутриенты этого блюда в приёме пищи автоматически пропорционально пересчитываются под новый вес порции.

## 2. Кнопка «Изменить» для продукта в Списке продуктов
- **Расположение**: В карточке каждого продукта во вкладке «Список продуктов» (`FoodLibraryTab.tsx`) добавить кнопку **«Изменить»** (`Edit3`) слева от кнопки «Добавить в список покупок». Итоговый порядок кнопок в карточке:
  1. **Изменить** (слева)
  2. **Добавить в список покупок**
  3. **Добавить в дневник (`+`)**
  4. **Удалить**
- **Функционал**:
  - При нажатии на кнопку «Изменить» открывается окно редактирования продукта **исключительно в ручном режиме** — без загрузки фото, без сканера этикеток и без кнопок ИИ.
  - В окне предзаполняются текущие данные продукта: **название**, **граммаж базовой порции** и **все нутриенты** (КБЖУ + дополнительные нутриенты с возможностью раскрыть и отредактировать или добавить любой нутриент вручную).
  - При сохранении обновляется карточка этого продукта только в «Списке продуктов» (уже записанные блюда в «Дневном меню» остаются без изменений).
