# План: Удаление счётчика разделов в Настройках и добавление блока «Информация» о лимитах ИИ

## 1. Удаление счётчика открытых разделов в шапке Настроек
- В верхней строке вкладки **Настройки** (рядом с заголовком `Разделы настроек` / `Settings Sections` / `Sekcje ustawień` и кнопкой `ⓘ О приложении`) полностью уберём плашку со счётчиком `0 из 9` (`0 out of 9` / `0 z 9`).
- В шапке останутся только название раздела, компактная кнопка `ⓘ О приложении` и кнопка установки PWA.

---

## 2. Кнопка «Информация» и автопоказ объяснения при первом нажатии «Пополнить / Ввести ключ»

Добавим небольшую кнопку **«ⓘ Информация»** (`Info` / `Informacja`) как в саму карточку **«Баланс ИИ-запросов и ключ доступа»** в Настройках, так и внутрь модального окна **«Пополнить / Ввести ключ»**:

```
[ Карточка в Настройках: Баланс ИИ-запросов и ключ доступа ]
  ├── Заголовок + бейдж «Осталось: X / Y» + маленькая кнопка [ ⓘ Информация ]
  └── Кнопка [ Пополнить / Ввести ключ ]
             │
             ▼
[ Модальное окно: Пакет на 500 ИИ-запросов ]
  ├── Шапка окна + кнопка [ ⓘ Информация ]
  ├── Раскрывающийся блок «О работе ИИ-ассистента и почему здесь есть лимиты 💡»:
  │     • При ПЕРВОМ открытии окна: блок автоматически РАЗВЁРНУТ,
  │       чтобы пользователь сразу прочитал честное объяснение правил
  │       (100 бесплатных запросов на старте, бесплатный ручной режим навсегда,
  │        пакет +500 запросов для покрытия затрат на серверы нейросети).
  │     • После первого открытия (сохраняется флаг в памяти браузера):
  │       блок по умолчанию СКРЫТ, чтобы не занимать место, и открывается/закрывается
  │       в один клик по кнопке [ ⓘ Информация ].
  ├── Статус текущего баланса + кнопка покупки пакета на 500 запросов
  └── Поле ввода и активации ключа
```

### Поддержка языков (RU / EN / PL)
- Для русского языка (`RU`) будет использован **в точности ваш авторский текст** со всеми абзацами и пунктами (`🎁 100 бесплатных ИИ-запросов на старте`, `✍️ Бесплатный ручной режим без ограничений`, `🔋 Дополнительный пакет на 500 ИИ-запросов`).
- Для английского (`EN`) и польского (`PL`) языков будут добавлены точные переводы этого же текста, чтобы интерфейс оставался полностью локализованным при переключении языка.
- Внутри модального окна будет работать плавная вертикальная прокрутка, чтобы при развёрнутом блоке информации все элементы окна оставались удобными на любом экране телефона.
