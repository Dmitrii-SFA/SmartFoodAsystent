# Обновление вкладки «Продукты»: добавление в список покупок и сворачивание дополнительных нутриентов

Обновление упрощает работу с библиотекой продуктов: в каждой карточке продукта появляется иконка тележки для мгновенного добавления в список покупок, а в модальном окне добавления нового продукта (по названию через ИИ, по фото этикетки, по фото блюда или вручную) все дополнительные нутриенты сворачиваются по умолчанию под кнопку раскрытия, чтобы базовые КБЖУ и кнопка «Сохранить в библиотеку» были доступны сразу без долгой прокрутки.

## User Review & Critical Decisions

> [!IMPORTANT]
> Ниже приведены решения, подтверждённые в ходе уточняющих вопросов:

- **Подтверждённое решение 1 (Иконка тележки в карточке продукта)**: Слева от кнопки `+` (записать в дневник) и иконки удаления (корзины) добавляется кнопка с иконкой тележки (`ShoppingCart`), которая в **1 клик** сразу отправляет продукт в список покупок (с размером порции по умолчанию, например `100 г`) и показывает уведомление, аналогично дневному меню.
- **Подтверждённое решение 2 (Сворачивание дополнительных нутриентов при добавлении продукта)**: В окне добавления продукта (при расчёте через ИИ по названию, распознавании фото этикетки, фото блюда или ручном вводе) сверху всегда открыты только основные базовые нутриенты (КБЖУ), а блок дополнительных нутриентов по умолчанию свёрнут под компактную кнопку раскрытия со счётчиком заполненных/распознанных нутриентов.

## 1. Overview & Core Concept

- **Что делает обновление**:
  1. Позволяет отправлять любой продукт из библиотеки прямо в «Список покупок» одним нажатием на иконку тележки, расположенную слева от кнопок `+` и удаления.
  2. Убирает необходимость длинной прокрутки вниз в модальном окне добавления продукта после распознавания ИИ по названию или фото этикетки: сразу под основными КБЖУ располагаются свёрнутый спойлер дополнительных нутриентов и кнопка «Сохранить в библиотеку».
- **Целевой сценарий использования**: Быстрое пополнение списка покупок из базы продуктов и мгновенное сохранение новых продуктов, распознанных через ИИ или камеру, на экранах смартфонов и десктопов.
- **Ключевая ценность**: Экономия времени — добавление в покупки в 1 клик и сохранение нового продукта без вертикального скролла через десятки полей витаминов и минералов.

## 2. User Experience & Visual Design

- **Ключевые пользовательские сценарии**:
  1. **Добавление продукта в список покупок**:
     - В шапке каждой карточки продукта во вкладке «Продукты» справа отображаются 3 кнопки действий (слева направо):
       1. **Иконка тележки** — добавляет продукт в «Список покупок» в 1 клик (`Название продукта`, количество `100 г` или указанный вес порции) и выводит всплывающее уведомление.
       2. **Кнопка `+`** — открывает окно быстрой записи продукта в приём пищи дневника.
       3. **Иконка корзины** — открывает подтверждение удаления продукта из библиотеки.
  2. **Компактное окно добавления продукта**:
     - Пользователь открывает модуль «По названию (ИИ)», «Фото этикетки», «Фото блюда» или «Вручную».
     - Вводит название или загружает фото и нажимает кнопку распознавания ИИ.
     - На экране сразу видны **Строка 1: Базовые КБЖУ** (Калории, Белки, Жиры, Углеводы).
     - Ниже располагается компактная кнопка-спойлер **«Показать дополнительные нутриенты»** с бейджем количества заполненных (ненулевых) дополнительных нутриентов (например, `Заполнено: 8 из 26`).
     - Сразу под этой кнопкой находится панель с кнопками **«Отмена»** и **«Сохранить в библиотеку»** — пользователю не нужно прокручивать длинный список микроэлементов.
     - При желании проверить или отредактировать витамины, минералы, клетчатку или сахар пользователь нажимает на кнопку-спойлер, и список дополнительных нутриентов (вместе с кнопкой «+ Добавить нутриент») плавно разворачивается.

- **Визуальный стиль и эргономика**:
  - Кнопка тележки выдержана в едином стиле с карточками дневного меню (`w-8 h-8 rounded-lg`, плавная подсветка изумрудным цветом при наведении и нажатии).
  - Кнопка сворачивания/разворачивания дополнительных нутриентов оформлена в едином стиле с вкладкой «Суточная норма» и «Настройка нутриентов», использует табличные цифры (`font-mono tabular-nums`) для счётчика заполненных полей.

## 3. Key Product Decisions & Trade-Offs

- **Решение 1: Добавление в список покупок в 1 клик с весом порции продукта**
  - *Выбранный подход*: Передача обработчика добавления в список покупок во вкладку «Продукты» и вызов его сразу при клике на иконку тележки с названием продукта и его стандартной порцией (`100 г` или `servingSizeGrams`).
  - *Почему*: Полная согласованность с поведением иконки тележки в дневном меню и рецептах; количество при необходимости легко корректируется прямо во вкладке «Покупки».
- **Решение 2: Автоматическое сворачивание дополнительных нутриентов при открытии окна и после ответа ИИ**
  - *Выбранный подход*: Состояние раскрытия дополнительных нутриентов по умолчанию закрыто (`false`) при открытии модального окна и остаётся свёрнутым после получения ответа от ИИ (при этом на кнопке обновляется счётчик распознанных дополнительных нутриентов).
  - *Почему*: Даже если ИИ рассчитал 10–15 витаминов и минералов, они сохраняются в карточку продукта, но не отодвигают кнопку «Сохранить в библиотеку» за пределы экрана.

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Архитектура и схема взаимодействия компонентов**:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         Корневое состояние приложения                   │
│  • library (библиотека продуктов)                                       │
│  • shoppingList + handleAddToShoppingList({ name, quantity, foodId })   │
└───────────────────┬─────────────────────────────────────────────────────┘
                    │ передача пропа onAddToShoppingList
                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                          Вкладка «Продукты»                             │
├───────────────────────────────────┬─────────────────────────────────────┤
│  1. Карточка продукта             │  2. Модальное окно добавления       │
│  ┌─────────────────────────────┐  │  • Ввод названия / Фото этикетки    │
│  │ Название и вес порции       │  │  • Кнопка расчёта через ИИ          │
│  │ [🛒 Тележка] [➕] [🗑️]      │  │  • Строка 1: Базовые КБЖУ (открыты) │
│  ├─────────────────────────────┤  │  • Кнопка-спойлер доп. нутриентов:  │
│  │ Строка 1: КБЖУ              │  │    [Показать доп. нутриенты (N)]    │
│  │ Строки 2–3: Доп. нутриенты  │  │  • Кнопка «Сохранить в библиотеку»  │
│  └─────────────────────────────┘  │    (сразу видна без прокрутки)      │
└───────────────────────────────────┴─────────────────────────────────────┘
```

- **Интерактивное управление состоянием**:
  - **Карточка продукта**:
    - Кнопка `ShoppingCart` размещается первой в группе кнопок действий карточки (`flex items-center gap-1.5 shrink-0`), слева от `Plus` и `Trash2`.
    - При нажатии вызывается `onAddToShoppingList({ name: item.name, quantity: `${item.servingSizeGrams || 100} ${t.gramsShort}`, foodId: item.id })`.
  - **Модальное окно добавления продукта**:
    - Добавляется локальное состояние `isSecondaryNutrientsExpanded` (по умолчанию `false`, сбрасывается в `false` в `handleOpenAddModal`).
    - Вычисляется количество заполненных дополнительных нутриентов `filledSecondaryCount` (где значение в `formNutrients` больше `0`).
    - Когда `isSecondaryNutrientsExpanded === false`, рендерится компактная кнопка раскрытия с иконкой `ChevronDown`, общим числом дополнительных нутриентов и бейджем заполненных значений (`Заполнено: X`), а сразу под ней — футер с кнопкой «Сохранить в библиотеку».
    - Когда `isSecondaryNutrientsExpanded === true`, отображается полный блок дополнительных нутриентов, кнопка «+ Добавить нутриент» и кнопка «Скрыть дополнительные нутриенты» (`ChevronUp`).
